# Personal Vehicle Management System

## Project Overview
The Personal Vehicle Management System is a mobile application designed to streamline vehicle information management for users. It offers features such as comprehensive vehicle inventory management, automated maintenance reminders, real-time GPS tracking, and customer relationship management.

## Key Features
- Real-time GPS tracking
- Unified platform for vehicle-related data
- Real-time updates on vehicle status
- Automated maintenance scheduling
- Compliance management
- Driver safety monitoring
- Fuel management

## Technology Stack
- Front End: Android Studio (Java)
- Back End: SQLite, Firebase

## Installation
### Prerequisites
- Android Studio (Java)
- SQLite
- Firebase

## Usage
### Admin Interface
- Manage vehicle inventory
- Schedule maintenance
- View real-time vehicle status

### User Interface
- View vehicle details
- Receive maintenance reminders
- Track vehicle location
